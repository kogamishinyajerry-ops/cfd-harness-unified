# 一个让AI写CFD代码"无处可逃"的项目：Codex 5轮审查的工程实录

## 当AI说自己通过了验证，你真的敢信吗？

2026年，一个用AI写CFD（计算流体力学）代码的开发者发现了一个尴尬的事实：他的代码"自报通过率"是80%，但经过独立AI审查后，第一次通过率是——0%。

这个项目就是**cfd-harness-unified**。它不仅解决了CFD验证的问题，还意外地成为了AI编程可信度研究的一个活生生的案例。

---

## 什么是CFD，为什么验证它这么难？

CFD（Computational Fluid Dynamics，计算流体力学）是工程师用数值方法模拟流体流动的技术。从飞机机翼设计到人工心脏瓣膜，从汽车风洞试验到核电站冷却系统，CFD无处不在。

**问题在于**：CFD模拟的结果需要满足严格的验证标准——不是"差不多就行"，而是必须精确到与实验数据对比在容差范围内。传统的验证方式是：

1. 工程师跑完模拟
2. 手动整理数据、做图、截图
3. 对照文献值计算偏差
4. 写报告
5. 合规官审查

**整个过程耗时30-60小时/案例**，而且充满主观性。

---

## 这个项目做了什么？

cfd-harness-unified构建了一个**自动化验证工作台**，包含三个核心创新：

### 1. 物理契约（Physics Contract）

每个CFD案例都有一个"黄金标准"——来自权威文献的参考值。例如Lid-Driven Cavity案例，引用Ghia 1982年的高精度数值解作为基准。

```yaml
physics_contract:
  - observable: "u_centerline"
    ref_value: 0.8412  # from Ghia 1982
    tolerance: 0.05    # ±5%
    precondition: "mesh resolution Y+ < 1"
```

代码在运行前必须声明满足所有前置条件，运行后必须通过容差验证。

### 2. 三态判决系统（Tri-State Verdict）

传统系统只有PASS/FAIL两种结果。这个项目发明了三态判决：

| 判决类型 | 含义 |
|---------|------|
| `contract_status` | 与黄金标准的数值对比 |
| `profile_verdict` | 剖面一致性（如17个采样点有多少在容差内）|
| `attestation` | 求解器收敛健康度（A1-A6六项检查）|

**关键洞察**：这三个维度独立变化。代码可能数值偏差（contract FAIL），但求解器健康（attestation PASS）。传统二态系统会掩盖这种复杂性。

### 3. Codex独立验证协议

这是最令人意外的部分。项目中引入了一个独立AI（Codex）作为"外部审计员"，专门审查开发AI写的代码。

**审查结果**：
- 开发AI自估通过率：80%
- Codex第一次审查通过率：0%
- Codex最终通过所需轮数：平均**5轮**

这意味着每一行代码都要经过5轮"质疑-反驳-修改-再质疑"的循环。

## 一个真实案例：LDC验证

Lid-Driven Cavity（驱动腔流动）是最经典的CFD基准案例之一。

项目运行结果：

```
contract_status: FAIL
  - u_centerline: 实测0.8123 vs 参考0.8412 → 偏差3.4%
  - v_centerline: 实测0.2791 vs 参考0.2863 → 偏差2.5%

profile_verdict: PARTIAL (11/17采样点在容差内)

attestation: ATTEST_PASS
  - A1 连续性收敛: ✓
  - A2 动量收敛: ✓
  - A3 残差趋势: ✓
```

**这个结果说明什么？**

数值偏离了参考值，但偏离程度在工程可接受范围内；求解器本身工作正常。这不是"假阳性"——它诚实地说"我对基准有偏差，但你知道原因"。

## 为什么AI审查比人类更严格？

Codex的审查发现了一些人类审查者容易忽略的问题：

1. **签名飘动问题**：HMAC签名每次调用重算，导致同一输入产生不同签名
2. **布尔值三态bug**：`partial`状态被错误处理为`False`
3. **单位不一致**：某些比较器混用了不同单位制
4. **分母为零保护**：边界情况处理不完整

这些问题不是"bug"——它们是真实世界中复杂系统必然产生的问题。AI审查的优势在于：**它不会因为"差不多"就放行**。

## 项目的意义

### 对CFD工程师

- **验证时间**：从30-60小时降到分钟级
- **可追溯性**：每一步决策都有文献引用和决策记录
- **可重复性**：同一案例、同一输入、同一结果（byte-reproducible）

### 对AI编程领域

- **可信度校准**：揭示了"自评80% vs 独立审查0%"的巨大落差
- **异质验证范式**：用另一个AI验证AI，这种"独立异质验证"协议可能成为AI系统可信度的标准
- **方法论输出**：物理契约schema + Codex审查流程可以复用到任何需要严格验证的领域
