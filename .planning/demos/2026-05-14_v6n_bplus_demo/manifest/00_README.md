## How to use this workspace (for the human running the demo)

**Day before demo:**
1. Read `01_segment_timing.md` end-to-end (5 min)
2. Read `03_speaking_cheatsheet.md` (5 min)
3. Dry-run Segments 2-4 commands from `02_live_commands.md` in a real terminal (10 min) — confirm every `cat`/`tail`/`grep` returns content fast
4. Pre-load HD HTML report in browser tab: `~/Desktop/apu-bay-ventilation-cht/reports/v6N/report_v6N_HD_v3_final.html` (22 MB) — keep tab open during demo
5. Record the 3 advisor-moment videos by opening a **fresh** Claude Code session in a recordable Terminal window and pasting the prompts from `advisor_transcripts/moment_{1,2,3}_prompt.md` — use QuickTime "New Screen Recording" → record each 90-s session → save to `recordings/moment_{1,2,3}_raw.mov`
6. Open CapCut, follow `06_editing_cutpoints.md` to cut & assemble (~30 min)

**Day of demo:**
1. Open Terminal in `~/Desktop/apu-bay-ventilation-cht` with font ≥ 18pt
2. Open browser tab on HD HTML report
3. Open final edited advisor-moments video file in QuickTime, ready to play in Segment 5
4. Open `03_speaking_cheatsheet.md` on phone/iPad as cue card
5. Start your own screen recording (Plan B in case live demo has issues) — QuickTime full-display
6. Go.

**Plan B if anything breaks during live demo:**
- Switch to the full-30min backup screencast you recorded the day before
- Or skip live Segments 2-4 and jump straight to Segments 5-6 (advisor moments + positioning) which need no live state
