## 0 · Scoring rubric (Codex relay grades against this · 100 pts total)

| Dim | Pts | What earns full marks |
|---|---|---|
| **L · Layout** | 20 | 5-zone grid proportions match · BottomBar is a CONNECTED RAIL not separated dots · per-mode secondary tab strip inside MainCanvas where the blueprint shows it · zone widths within ±5% of spec |
| **C · Color** | 15 | All v4 tokens used · accent <5% pixels · gradient on engine body · BC type colors map cleanly to severity palette · no off-token colors |
| **T · Typography & density** | 15 | KPI numbers ≥28px tabular-num · LeftRail tree at 10-11px Chinese · RightPanel pill title 12px · per-pixel info density on telemetry strips, breathing room on MainCanvas |
| **M · Mode content fidelity** | 25 | Each of 8 modes carries the SAME structural elements as its blueprint image (streamlines · histograms · BC labels · verdict pill · DOE grid · etc · checklist in §4) |
| **F · Industrial feel** | 15 | No decorative chrome · glass-wall enclosure visible · curved streamlines (not straight arrows) · connected pipeline rail · multi-detail status cards · STAR-CCM+/Fluent parity vibe |
| **P · Polish & interactivity** | 10 | Pipeline active-glow pulse · selection rings · hover transitions · cursor feedback · progressive disclosure on AdvisorPill · 4Q gate microcopy present |

**Pass threshold: ≥80.** Below 70 = redesign. 70-79 = iterate. ≥80 = ship the foundation.

## 2 · Global frame (constant across 8 modes)

### 2.1 TopBar (32px · `v4-shell` bg · 1px bottom border)
- LEFT: wordmark "CFD 全流程工作台" 12px regular (no logo glyph)
- CENTER: breadcrumb with dropdown chevrons
  - `APU 舱通风 ▾  ·  R-042 ▾  ·  计算时间 00:12:14  ·  Cluster-01 [128 核]`
  - chevron `▾` is 8px text-secondary · clickable suggested by hover
  - separators are mid-dot `·` text-tertiary
- RIGHT: AI 助理 button — leading 6px brand dot + label · hover raises surface

### 2.2 LeftRail (224px = 32 icon strip + 192 tree)
- Icon strip 32px wide: 10 vertical tabs · top-to-bottom labels (vertical text or icon-only):
  `案例 · 物体 · 几何 · 网格 · 物理 · 边界 · 仪表 · 求解 · 后处理 · 设计探索`
- Each tab: 28-32px tall · 16px icon glyph · active = surfaceRaised + active color · hover = surfaceRaised + textPrimary
- Tree column 192px: ≥12 visible tree items at 11px line-height
  - Hierarchy with 8-12px indent per level
  - Status dot on rightside per item: ✓ green / ⚠ amber / hollow gray
  - Section headers in 10px uppercase tracking-wider text-tertiary
  - Items have tiny chevron `▸` 8px on hover
- The active workspace category is the same as the active pipeline step

### 2.3 MainCanvas (flex · `v4-canvas` bg)
- **OPTIONAL secondary tab strip** at top (28px) when blueprint shows it (geometry · physics · mesh · post · DOE all show it; import · boundary · solver image 1 do not).
  - Tabs in 11px medium · active underline 2px active color
  - Right side of strip: micro-controls (e.g. checkboxes "时间格式 · 重力 g=9.8")
- 3D viewport area (rest of height):
  - Glass-walled isometric enclosure (transparent walls · visible edges · subtle ground shadow)
  - Central engine assembly with realistic detail level
  - Mode-specific overlays (streamlines · BC labels · histograms · etc · see §4)
  - Camera preset chips top-right (前 · 顶 · 轴侧) — 10px text-secondary
- Bottom edge of MainCanvas connects to KPI strip with no margin

### 2.4 KPI strip (96px · `v4-shell` bg · 1px top border)
- 4-6 chips in a horizontal row · 12px gap between chips · 14px h-padding
- Each chip: 100-140px wide · transparent bg (NOT raised surface) ·
  layout: optional 12px leading icon · then number cluster · label below
- Number cluster (vertical baseline aligned):
  ```
  28.6  M          ← number 28-32px semibold + unit 11px text-tertiary
  估算单元           ← label 10-11px text-secondary
  ```
- Delta badge (e.g. "+4.2%") right of number when relevant · 10px in tone color

### 2.5 BottomBar (60px · `v4-surface` bg · 1px top border)
- 7-step (or 8 with DOE) **CONNECTED RAIL**:
  - Horizontal line `border-v4-border` 1px running through the center of dots
  - Dot diameter: 10px done · 12px active · 8px pending
  - Done dot: filled `v4-healthy` + 8px white check overlay
  - Active dot: filled `v4-active` + 4px outer glow ring + animate-pulse
  - Pending dot: hollow 1.5px border text-tertiary
  - Step label below dot at 10px medium · active = text-primary · done = text-secondary · pending = text-tertiary
  - 8-step number above dot at 9px mono text-tertiary

### 2.6 RightPanel (300px · `v4-surface` bg · 1px left border)
- Header (32px): "AI 助理" 11px uppercase tracking-wider text-secondary + right-side advisory note "advisory only · 仅建议" 10px text-tertiary
- Card stack: each card 10-12px padding · 1px border v4-border · bg v4-surfaceRaised
  - **Variant A · status pill** (default): 8px severity dot · title 12px · meta 11px · CTA 10-11px right-aligned
  - **Variant B · detail card** (for modes like post / boundary): title + 2-3 key-value rows + CTA
  - Hover: border raises to v4-borderActive
  - Click expansion: progressive disclosure for full commentary

## 3 · 3D scene composition (`IndustrialBoxScene`)

The shared isometric SVG must give a **glass-walled, photorealistic-ish**
impression, not a wireframe diagram. Concrete contract:

### 3.1 Enclosure
- 6-face isometric box · front + top + right walls semi-transparent (12-18% fill opacity) so engine is visible inside
- Visible edges: 0.75px `v4-border`
- Ground plane: subtle hatch pattern (already shipped) + ground shadow under engine (radial blur 30px opacity 0.4)
- Wall corners: 2-3px subtle radius for soft edge

### 3.2 Engine
- Cylinder body (compressor section): use linear gradient simulating left-to-right metallic highlight
- Nozzle cone (right tail): solid darker shade
- Rotor disc (left): visible blades (≥6 blade lines) · slight rotation animation in solver mode
- Mounting brackets: 2 visible struts to ground
- Body should have at least 3 visual zones to suggest mechanical detail

### 3.3 Mode-variant overlays (see §4 for which mode uses which)
- **Streamlines**: ≥60 curved Bezier paths · color graded cool→hot · stroke-width 0.6-1.2px
  varying · opacity 0.55-0.9 · paths wrap from inlet around body to outlet
  - NOT straight arrows. The blueprint's defining feature.
- **BC patches**: opaque colored overlays attached to body surfaces (inlet/outlet/wall/rotor) with hovering callout labels (leader line + rounded rect)
- **Wireframe**: superimpose 1px subdivision grid on body surface (mesh mode)
- **Contour surface**: paint body in velocity colormap (post mode)

### 3.4 Performance budget
- Total SVG nodes per scene ≤ 600 (browser perf · don't pathological)
- No animations heavier than CSS transforms / opacity / dasharray

## 5 · Interaction & polish contract (P dimension)

- ✅ Pipeline active dot: 2s animate-pulse with 8px glow halo
- ✅ DOE thumbnail selection: 2px ring (active color) + transform scale 1.02 transition 150ms
- ✅ AdvisorPill expand/collapse: 150ms ease transition · `aria-expanded` toggles · keyboard accessible
- ✅ Hover on tree items / pills / chips: border color step to `v4-borderActive` 100ms ease
- ✅ Camera preset chips: visual press feedback even though no-op behind the scenes
- ✅ Microcopy:
  - RightPanel header MUST contain "advisory only · 仅建议" (V130 enforcement)
  - NO words: "AI generates / AI suggests / AI diagnoses / AI recommends / AI advises"
- ✅ Loading states: skeleton or muted "加载中" not blank
- ✅ Empty states: "暂无 …" not "no data" / not "error"
