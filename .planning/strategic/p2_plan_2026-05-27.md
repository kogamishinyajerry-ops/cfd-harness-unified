## Goal (one line)

Catch bad/likely-wrong CFD setups **before** the expensive solve (pre-flight signals), and
distill the death-mode corpus into the **offline** advisor ruleset so the workbench advises
LLM-free at runtime (Law-3). Both strictly **advisory-only** (DEC-V61-130/132 untouchable).

## Why now (motivating evidence)

P1's flat-plate arc (DEC-V61-209) burned ~8 solve cycles on exactly the failure classes
pre-flight is meant to pre-empt: Re mismatch (2e6 vs NASA 5e6 → 15–17% error), y+~120 vs
canonical y+~1, freestream Tu 600× off canonical. A deterministic pre-flight signal would
have flagged all three before the first Docker solve. P2 turns this session's hard-won lessons
into reusable, offline guardrails.

## Recommended FIRST increment → **W1.1 (flow_coherence pre-flight)**

Highest value (directly operationalizes this session's lessons + fills the two "High" blocker
gaps), lowest risk (additive category, advisory-only, no route change, no schema break — just a
new `str` category + rows + tests). Deterministic and LLM-offline by construction.

**Acceptance (W1.1 passes):**
1. `build_preflight("flat_plate_rans_sst")` emits a `flow_coherence` category with a Reynolds-
   coherence row (pass: Re/L=5e6 matches gold) and a y+ row (advise: y+~1.3 in-band).
2. A Re-mismatched fixture (e.g. ν=1.5e-5 → Re/L=2e6) yields a **fail** row whose `evidence`
   names the measured vs expected Re and `consequence` names the wasted-solve risk.
3. Zero writes (advisory-only); `require_loopback` intact; four-question gate answered in the
   commit body.
4. New pytest covers both the pass and fail fixture; full sweep green (incl `cfdtrust_tests/`).
5. Correctness-critical shared code → Codex review (cap=3) before commit.

## Guardrails (persist at L2 — non-negotiable)
- **Advisory-only**: pre-flight + ruleset NEVER mutate a case dir (DEC-V61-130/132). Enforced by
  existing tests + four-question gate on every increment.
- **LLM-offline**: every new predicate/check is a pure function; `test_stack_zero_llm_imports`
  must stay green.
- **No silent gate-tuning**: pre-flight signals are advisory, not pass/fail gates on the V&V
  tolerance — they never touch the DEC-209 reference tolerances.
- **Truth-chain**: every distilled rule cites its V-row provenance; no fabricated rules.
