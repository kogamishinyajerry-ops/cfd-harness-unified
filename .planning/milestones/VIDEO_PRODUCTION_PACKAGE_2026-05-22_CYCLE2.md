## Operator notes

- **Renderer is deterministic**: re-running produces byte-identical MP4 (modulo ffmpeg version). All scene values are computed from time-only inputs.
- **Re-rendering after engine code changes**: if the engine moves and you want fresh captures, regenerate captures via the corresponding commands (see `Real artifacts inventory` table), then re-run the renderer.
- **Asset upgrade path**: if you want a higher-res version, change `W, H = 1280, 720` to `W, H = 1920, 1080` and `FPS = 24` to `FPS = 30`. Frame budget grows ~3.4×; expect ~7-8 min render on M-series.
- **Voice-over track**: this package ships VO scripts in `SCREENCAST_SCRIPT_CYCLE2.md`. Recording is OUT OF SCOPE for the marketing-director agent — that's a separate operator step (record AAC, mux with `ffmpeg -i video.mp4 -i vo.aac -c:v copy -c:a aac out.mp4`).
- **Subtitle track**: not embedded in this MP4 — the on-screen Chinese IS the subtitle. If you need an SRT (e.g. for non-Mandarin viewer), generate it from the per-scene Chinese strings in `SCREENCAST_SCRIPT_CYCLE2.md`.
