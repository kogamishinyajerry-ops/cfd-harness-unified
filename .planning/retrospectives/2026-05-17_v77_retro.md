## What worked

1. **Greenfield SSE was 2 hours, not 2 days**.
   The "7 arcs aged bookmark" turned out to be smaller than expected. Hook + 3 components + tests + tests-for-EventSource-mock pattern total ~600 LOC. Same lesson as V76: bookmarks age in proportion to "if I never measure it, no one will notice." Pillar 16's existence flipped the gravity vector.

2. **EventSource mock pattern is reusable**.
   `makeFakeES()` factory exposes `__emit / __open / __error` synchronous triggers inside `act()` boundaries. 7 contract tests for components + 6 unit tests for the hook = 13 new tests in <30 min. V78+ should generalize this into a `tests/setup/sseMock.ts` if more SSE consumers land.

3. **Playwright --update-snapshots solved V76 carry retroactively**.
   V76 close DEC §5 honestly disclosed "snapshot capture deferred to live env". V77 had a working playwright environment (uv backend + vite dev server auto-spawn from playwright.config.ts webServer) so the same `--update-snapshots` invocation captured V76's 11 pending PNGs + V77's 8 new ones in one pass. **Lesson**: don't carry-defer when one command would close it.

4. **SwiftShader WebGL fix was 4 lines of config**.
   `launchOptions.args: ["--enable-webgl", "--use-gl=angle", "--use-angle=swiftshader", "--ignore-gpu-blocklist"]`. Future arcs that add vtk content can trust headless playwright now.

## What surprised us

1. **3 regressions appeared at iter-1, all from the same un-fixed import**.
   `vi` was imported but unused in SolverStream.contract.test.tsx. This triggered:
   - lint error → quality 80 → 50
   - typecheck error → smoke 54 (frontend_build=0)
   - test runs continued because vitest doesn't care about TS-only errors
   Fix was 1-character (deleted `vi` from import list). **Lesson**: a single hygiene miss can fail 3 pillars simultaneously. The 2.3 spec convention `confidence: low` should auto-trigger eslint+tsc pre-commit on test files specifically.

2. **SwiftShader enables WebGL but also changes font rendering for non-WebGL screenshots**.
   V74 baselines 47/48 (TruthChain right-panel · no vtk content) drifted after SwiftShader on. Anti-aliasing pipeline shifted just enough to fail maxDiffPixelRatio=0.01. **Lesson**: any "render flag flip" affects more than the intended surface. Re-snapping was correct, but a 5-arc-aged SSIM tooling switch would have made this drift invisible noise instead of a real failure.

3. **Pillar 16 from 12 → 100 in one substrate drop**.
   iter-0 had useSseResidualStream.ts landed (12 = partial credit for hook ref + missing status testid). iter-1 with all 3 components mounted scored 100. **Lesson**: when scorer subscores require literal-testid presence in JSX, the path from 0→100 is binary per subscore. The literal-testid scorer patch from V76 made this clean (no template-expression workarounds needed).
