## What worked

1. **"Closing the retro Open Q list" was the perfect arc theme.**
   The 18th mandate was explicit: "continue, complete all suggestions". This pinned arc scope to a finite, well-documented list of 4 items. Each sub-DEC had a clear "done" criterion. The arc didn't risk scope creep because the scope was set before the arc started. **Lesson**: retro Open Q items aging across arcs build up substrate debt; a dedicated "close-all-the-Open-Qs" arc once every 4-5 arcs is a healthy cadence.

2. **The flake fix took 5 minutes once reproduced.**
   V81.5 disclosed the flake honestly but didn't fix it (substrate was orthogonal). V82.3 attempted reproduction in 15 sequential `npm run test` runs — caught 1 failure (7% rate) — read the failing log — identified `getByText("Mesh OK")` post-`waitFor("mesh-quality-card")` race — applied `findByText` to both occurrences — re-ran 15 times, zero failures. **Lesson**: V79 + V80 + V81 ran the stability scorer 3× per iter for FOUR arcs while this flake existed. Total wasted-retry compute time ≫ the 5 minutes the fix took. Lazy retry-on-flake is a real cost.

3. **Backend SSE 4-layer model was the most CFD-credibility-rich V82 substrate.**
   V78.1 produced a 6-variable log-residual decay with sinusoidal noise. A CFD reviewer would look at that and immediately call it synthetic. V82.4 adds: initial spike (linear-solver adjustment phase), pressure-momentum coupling lag (~3 iters), two plateau regions (~50-75, ~120-145), k-ω slowdown (turbulence-eq under-relaxation). All shapes a CFD engineer would expect from a steady simpleFoam k-ω SST run. The change is ~50 LOC inside a single pure function. **Lesson**: physical realism in synthetic substrate doesn't require a real solver — it requires reading the literature and replicating shape, not magnitude. The cost is low; the demo credibility uplift is high.

4. **10/10 Gold-Standard commentary feels like substrate completeness.**
   V80 had 1/10. V81 had 3/10. V82 has 10/10. Each case carries 3 curated commentary kinds (mesh / convergence / result) keyed by step. A novice exploring the workbench can now click into any of the 10 canonical cases and read commentary that cites real CFD literature (Williamson 1989 / Driver-Seegmiller 1985 / Moser-Kim-Mansour 1999 / Ghia 1982 / de Vahl Davis 1983 / Cooper 1993 / Kerr 1996 / Gavrilakis 1992 / AGARD AR-138 / NASA TM-85961 / Menter 1994 / Schlichting / Versteeg-Malalasekera / Pope). **Lesson**: depth × breadth becomes credibility.
