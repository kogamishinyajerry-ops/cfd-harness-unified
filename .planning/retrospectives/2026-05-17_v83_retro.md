## What surprised us

1. **The DemoBanner hook-order bug cost 5 minutes mid-arc.**
   First attempt at cinematic-mode tests crashed with "useLocation may be used only in the context of a Router" — but the actual root cause was BEFORE that: I placed `useRef` + `useEffect` AFTER an early-return-for-cold-state. React caught it as a hook-order violation. Fix: move all hooks above the first conditional return. The test caught it on the first run, no production exposure. **Lesson**: existing components with early returns are dangerous places to add state. A grep sweep for `useState\|useRef\|useEffect` placement relative to conditional `return` statements would be a V84 spike (≤1 hour).

2. **The Router-dependency leakage to AdvisorContent broke 7 router-less tests.**
   Added `useSearchParams` to AdvisorContent for `?failmode=1` detection → 7 of the existing contract tests broke immediately because they didn't wrap with MemoryRouter. Right fix: lift `failmodeActive` to a prop passed from WorkbenchShellV3 (already inside Router). **Lesson**: shared components should be Router-agnostic. Receive Router state as props from the closest Router-aware ancestor. Easier to unit-test, easier to compose.

3. **V82.3 flake fix continues to be load-bearing.**
   V82 close had iter-2 first attempt fail at 70 (stability flake) and require retry. V83 had ZERO flakes across 3 iters. The fix to `MeshQualityCard.test.tsx` (`getByText` → `findByText`) doesn't just close V81 retro Open Q #2 — it makes the close gate qualitatively cleaner for every subsequent arc. **Lesson**: test infrastructure debt fixes have score-evidence dividends. V79 + V80 + V81 each paid a "retry-on-flake" tax; V82 + V83 don't. Worth front-loading similar fixes when discovered.

4. **iter-0 already at 100/100 is the new normal for substrate-orthogonal arcs.**
   V82 + V83 both hit 100 immediately. The pattern is consistent: when an arc adds NEW files vs MODIFIES existing-tested files, baselines stay clean. Strategic-pivot arcs (V80 = first new blueprint · V83 = V5 blueprint) are NOT inherently dirtier than substrate arcs — they're often cleaner because contracts force isolated new components.
