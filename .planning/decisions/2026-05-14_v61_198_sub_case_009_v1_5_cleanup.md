## 1. Context

V91 (Track C session 4, 2026-05-13) blind-verified that V41's `[VALIDATED 2026-05-08]` sediment was empirically false: `08b_load_chemistry_mech.py:patch_thermo_header` only rewrites the global header of GRI-3.0 `therm.dat`, leaving 13 of 53 species (including dominants **N2** and **AR**, plus 11 trace species) with per-species records declaring `G 300.000 <Thigh> 1000.000`. chemkinToFoam writes those per-species Tlow values verbatim into `constant/thermo.compressibleGas`, where janafThermo's per-species limiter then fires at every cell with T<300. v1's `0/T fuel_jet` boundary at 294 K — Sandia Flame D spec — triggered the flood: `8.86M` warnings in **593 μs** of ignite time, before any flame established. V91 deferred patch-completion to "case_009 v1.5 / v2 sub-session". **This sub-DEC is that v1.5 session.**

## 2. Decision

Land a two-pronged remediation in the external substrate `~/Desktop/case_009_sandia_flame_d/` (case_009 is an industrial reference outside the main repo):

1. **New patch script** `v1_5/scripts/patch_janaf_tlow.py` — argparse CLI, idempotent, brace-depth-aware top-level species-block parser, writes `.pre_tlow_patch` backup before mutating. Lowers each species' `Tlow N;` to `Tlow target;` (default `target=200`) when `N>target`. Prints an audit table `(species, old, new)`.
2. **v1.5 case dir** `v1_5/case/` — `rsync`-clone of `case/` (excluding the 5.3 GB v1 log files), patched, restarted from cold-flow latestTime (`t=0.005`), endTime extended to `0.007` (2 ms ignite window), `fieldMinMax` functionObject added for T / CH4 / OH / H2O / CO2 / Qdot. fuel_jet inlet T retained at **294 K** (Sandia spec preserved; the Tlow patch is the lower-perturbation fix vs alternative `294→300 K` bump).
