## Decision

Land the physics commit pipeline end-to-end:

- Backend writer translating MaterialContract + RegimeContract →
  `constant/physicalProperties` + `constant/momentumTransport`
- New POST route `/api/cases/{case_id}/physics`
- V132 registry update (HTTP surface + Python symbol)
- Standalone PhysicsPanel React component with preset dropdowns,
  readouts, applicability badges, citation links
- Frontend preset library mirror with backend↔frontend parity test

## Wire contract

```python
class PhysicsCommitRequest:
    material: MaterialContract
    regime: RegimeContract

class PhysicsCommitResponse:
    case_id: str
    written_paths: list[str]    # ["constant/physicalProperties",
                                #  "constant/momentumTransport"]
    dict_texts: dict[str, str]  # echo of what was written
    committed_at: str           # ISO 8601 UTC
```

Status mapping:
- 200 → `PhysicsCommitResponse`
- 400 → bad case_id (path-traversal probe)
- 404 → `failing_check: case_not_found`
- 422 → `failing_check: case_not_scaffolded` (constant/ missing)
   OR Pydantic validation error
- 502 → `failing_check: physics_write_failed` (disk-full / perms)

## Writer behavior

- Emits transportModel + nu always
- Thermal block (rho + Cp + kappa + Pr) emitted only when
  MaterialContract.thermal is set — incompressible-isothermal cases
  produce the same minimal dict that bc_setup.py has been writing
  since V61-097
- Atomic write (mkstemp + os.replace) so concurrent reads never
  observe partial dicts
- `momentumTransport`:
  - laminar → `simulationType laminar;`
  - RANS-RAS → `simulationType RAS;` + RASModel kEpsilon block
  - RANS-kOmegaSST → `simulationType RAS;` + RASModel kOmegaSST block
  - LES-stub → laminar fallback + TODO comment directing engineer to
    edit by hand for actual LES sub-grid model

## Reproducibility (charter §"preset values are NOT auto-bound")

Selecting a preset shallow-copies its `fluid`/`thermal`/`applicability`
into the wire body. Library bumps DO NOT silently mutate saved cases.
Audit trail records `kind=preset` + `preset_id` so the engineer (and
later post-mortem readers) can see which library version applied.
