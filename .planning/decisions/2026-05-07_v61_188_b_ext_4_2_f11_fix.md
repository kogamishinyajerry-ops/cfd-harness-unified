# DEC-V61-188 · B-Ext-4.2 F11 fix

## Status

**Accepted 2026-05-07** — workbench-side fix wires the existing
`write_run_artifacts(...)` service into the `/solve` route. Closes
F11 (run-history empty after successful /solve, surfaced in
B-ext-3.4 R7 + curl direct E2E).

## Root cause

`reports/{case_id}/runs/{run_id}/{measurement.yaml,verdict.json,
summary.json}` is populated by `RealSolverDriver.execute()` (M3
closed-loop main-line). The legacy `/api/import/{case_id}/solve`
route calls `run_icofoam` directly without invoking
`write_run_artifacts`, so successful runs are never recorded. R7 +
curl E2E observed `GET /run-history → 200 {"runs": []}` after a
verified `/solve POST 200` with SolveSummary `converged=True`.

This breaks the Step 6 persona post-solve flow (the prompt routes
persona through `/run-history` for run_id discovery, then to
`/results/{run_id}/field/{name}` for raw field bytes).

## Fix

`/api/import/{case_id}/solve` route now:

1. Records `started_at` before invoking `run_icofoam`
2. On success, generates a `run_id` via `new_run_id()` and calls
   `write_run_artifacts(...)` with:
   - `started_at` + `duration_s = result.wall_time_s`
   - `success = result.converged`, `verdict_summary = "converged"|"ran_but_not_converged"`
   - `key_quantities = {end_time_reached, n_time_steps_written}`
   - `residuals = {p, Ux, Uy, Uz, continuity}`
   - `source_origin = "ui_solve_route"` (distinguishes from
     `RealSolverDriver` callers)
3. Wraps the artifact write in `try/except (OSError, ValueError):
   pass` — best-effort persistence doesn't fail the /solve response
4. Returns `SolveSummary` with new `run_id: str | None` field so
   callers can drill into the persisted artifacts directly

On run_icofoam failure, `write_run_artifacts` is NOT called — the
case keeps a clean run-history with no orphan partials.

## Schema change

`ui/backend/schemas/case_solve.py` adds `run_id: str | None = None`
to `SolveSummary`. Backward-compatible: existing callers that
deserialize SolveSummary without expecting `run_id` continue to
work; new callers can read the field.
