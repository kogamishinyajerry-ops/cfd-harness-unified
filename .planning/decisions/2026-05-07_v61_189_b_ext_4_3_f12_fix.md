# DEC-V61-189 · B-Ext-4.3 F12 mitigation

## Status

**Accepted 2026-05-07** — two-pronged mitigation. Persona prompts
gain stronger Step 4 guidance to use `from_stl_patches=1` with
case-physics bc_contract. Workbench-side LDC executor surfaces a
soft warning when invoked on geometry that's clearly not the
cavity tutorial cube.

## Root cause

R7 + curl direct E2E (DEC-V61-184) found that the LDC default
executor on NACA0012 (`from_stl_patches=0` or no query param) wrote
`lid_velocity=(1,0,0)`, `nu=1e-3`, `Re=100` BC values with
bbox-derived `lid`/`fixedWalls` patches. icoFoam "converged"
residuals (last_initial_residual_p ~7.7e-4) but produced 1584
NaN U field entries — physically meaningless because the airfoil
isn't a cavity. Persona had no workbench-side signal that LDC
defaults were wrong.

## Fix Part A — persona prompts (Step 4 guidance)

All 3 persona prompts gain a "Step 4 — `from_stl_patches=1` is
mandatory for non-LDC geometry" section:

- **novice.md**: explains LDC defaults are calibrated only for the
  cavity tutorial cube; for any other geometry, POST
  `/setup-bc?from_stl_patches=1&solver_name=...&inlet_speed=...&nu=...&end_time=...`
  with values from the case brief.
- **experienced_fluent.md**: same content with a concrete NACA0012
  example (`inlet_speed=14.6` m/s, `nu=1.45e-5` at chord-Re=1e6).
- **debug.md**: emphasizes that omitting `from_stl_patches=1` routes
  through `setup_ldc_bc` which produces NaN field on non-LDC; if
  `/results-summary` returns 422 `results_malformed` with NaN, the
  remediation is re-POST with `from_stl_patches=1` + explicit
  physics.

42/42 persona library + assignment + runner tests pass.

## Fix Part B — workbench-side LDC geometry-mismatch warning

`ui/backend/services/case_solve/bc_setup.py`:

1. `BCSetupResult` dataclass gains `warnings: tuple[str, ...] = ()`
2. New helper `_ldc_geometry_mismatch_warnings(case_dir)` reads
   `case_manifest.yaml`'s `ingest_report_summary.bbox_extent`, computes
   max/min ratio, returns a warning tuple if aspect > 3.0:

   ```
   ldc_geometry_mismatch: bbox_extent=[1.0, 0.12003, 0.1] has aspect
   ratio 10.00 (> 3.0). The LDC default executor hardcodes
   lid_velocity=(1,0,0), nu=1e-3, Re=100 and is calibrated for the
   lid-driven cavity tutorial CUBE. ... Re-POST
   /setup-bc?from_stl_patches=1&solver_name=...&inlet_speed=...&nu=...
   &end_time=... with values from your case brief.
   ```

3. `setup_ldc_bc` populates `result.warnings` from the helper
4. Best-effort: missing/unreadable manifest returns no warning (doesn't
   fail setup-bc); near-cube geometry (aspect ≤ 3) returns no warning

`ui/backend/schemas/case_solve.py`: `SetupBcSummary` gains
`warnings: list[str] = Field(default_factory=list, ...)`. The N1.1
apply route surfaces `warnings=list(ldc_result.warnings)` in the
SetupBcSummary response. Persona reads it via /setup-bc HTTP
response body.
