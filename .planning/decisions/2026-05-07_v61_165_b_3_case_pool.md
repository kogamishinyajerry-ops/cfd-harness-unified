# DEC-V61-165 · B.3 · Case Pool

## Scope

Land the 3 case fixtures consumed by the B-arc dogfood. Each case
has: a JSON brief (consumed by `case_brief.load_brief`), a
programmatically generated low-tessellation STL (committed for
deterministic harness imports), and a reference value from
literature with stated tolerance.

All three cases are **non-LDC** (LDC was already in N1-N5 fixtures);
they exercise post-N6 fresh-eyes friction on real CFD geometries.

## Surface delivered

- `scripts/dogfood/cases/__init__.py` — package marker + helpers
- `scripts/dogfood/cases/README.md` — reference data citation
  table + geometry sketch + caveats
- `scripts/dogfood/cases/geometry_generators.py` — programmatic
  ASCII STL writers (3 functions, each pure-stdlib, deterministic)
- `scripts/dogfood/cases/briefs/naca0012.json` — Cl ≈ 0.44 ±5% rel
  (Abbott & Doenhoff 1959 §Fig 4-5 linear region)
- `scripts/dogfood/cases/briefs/backward_step.json` — reattachment
  L/h ≈ 6.0 ±10% rel (Kim et al. 1980, ER=2 Re=5000)
- `scripts/dogfood/cases/briefs/pipe_expansion.json` — pressure
  recovery Kp ≈ 0.5625 ±5% rel (White Fluid Mechanics §6,
  Borda-Carnot for sudden ER=2)
- `scripts/dogfood/cases/geometry/naca0012.stl` — extruded NACA0012
  profile, ~80 facets
- `scripts/dogfood/cases/geometry/backward_step.stl` — 12-facet
  box-with-step domain (ER=2, step height = 1)
- `scripts/dogfood/cases/geometry/pipe_expansion.stl` — two coaxial
  16-side cylinders sharing the expansion plane, ~96 facets
- `tests/dogfood/test_cases.py` — load each brief, regenerate each
  STL deterministically, parse-back facet count, check_verdict at
  known-good / known-bad observed values

## Reference values (charter §rationale)

| Case | Metric | Reference | Tolerance | Source |
|---|---|---|---|---|
| `naca0012` | Cl at Re=1e6, AoA=4° | 0.44 | ±5% rel | Abbott & Doenhoff 1959 |
| `backward_step` | reattachment length L/h at ER=2, Re=5000 | 6.0 | ±10% rel | Kim et al. 1980 |
| `pipe_expansion` | pressure recovery Kp at sudden ER=2 | 0.5625 | ±5% rel | White Fluid Mechanics §6 (Borda-Carnot) |

NACA0012 reference: linear-region slope ≈ 2π per radian; AoA=4° =
0.0698 rad → Cl ≈ 0.439. Tabulated Abbott & Doenhoff Fig 4-5
agrees within 1%. We use 0.44 with ±5% relative tolerance to
absorb solver-side error, mesh resolution sensitivity, and
turbulence-model variance (k-ω-SST vs Spalart-Allmaras differ
~2-3% on this case).

BFS reference: Kim, Kline, Johnston 1980 reports L/h between 5.5
and 6.5 for ER=2 at Re=5000 across multiple turbulence
treatments. We use 6.0 ±10% to accept either end.

Pipe expansion Kp: closed-form Borda-Carnot for sudden expansion
gives Kp = (1 - A1/A2)² = (1 - 1/4)² = 0.5625. ±5% absorbs entry
length effects + turbulent dissipation correction.

## STL fixture design

Geometry is **representative not high-fidelity**. Personas drive
the workbench through Steps 2-5 (mesh → physics → BC → solver) on
these meshes; CFD result quality depends on the workbench's
meshing + solver choices, which is the SUT. We commit
small-tessellation STLs (<5 KB each) for repo-size hygiene and
deterministic harness inputs.

- NACA0012: 30 chord-wise segments (60-pt closed profile);
  extrude to thickness=0.1 spanwise; triangulate top + bottom
  surfaces + side caps. ~80 facets.
- BFS: hardcoded 8-vertex domain (10h streamwise × 2h cross ×
  unit spanwise) with step subtracted. 12 facets.
- Pipe expansion: two coaxial cylinders, 16 sides each, sharing
  the expansion plane. ~96 facets.

Generators are PURE-STDLIB (math only) and DETERMINISTIC; tests
regenerate and byte-compare against committed STLs.

## Notes

- Geometry quality is intentionally low. If B.4 surfaces "the
  STL is too coarse for meaningful Cl computation" as a friction
  log entry, that's a B.5 backlog candidate. We do NOT pre-empt
  by shipping high-fidelity meshes; the dogfood is testing
  workbench UX + advisor signal-to-noise, not solver accuracy.
- Pipe expansion as 2D-axisymmetric is the cleaner CFD setup,
  but workbench mesh-quality advisor expects 3D surface mesh
  inputs; we ship a 3D fixture (two cylinders) and let the
  persona decide whether to use axisymmetric BC + 1-cell-thick
  meshing or full-3D.
- BFS aspect ratio 10:2:1 keeps the mesh small for serial
  testing in B.4 (target run time <5 min per case under
  `simpleFoam` baseline).
- Reference values are stated as **floating-point literals**
  in JSON (not formulas) so brief load is pure JSON parse with
  no eval.
