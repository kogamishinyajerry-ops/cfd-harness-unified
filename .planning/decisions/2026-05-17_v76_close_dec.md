## 5 · Honest disclosures

### What V76 did NOT do
- Did NOT integrate SSE residuals (V71.L bookmark · 7 arcs aged · carry to V77).
- Did NOT smoke-test backend audit-package round-trip (carry from V74 close §5 · still unverified).
- Did NOT switch pixel-ratio → SSIM tooling (4 retros now mentioned · carry to V77 priority).
- Did NOT tighten UX scorer threshold to 100% specs (Open Question from V75 retro).
- Did NOT run playwright on V76 baselines 61-68 in this session — test definitions land, snapshot generation requires a live dev server + backend. Substrate verified via 5/5 vitest contract tests + scorer regex hits.

### Substrate fragility uncovered
- Baselines 24 / 25 / 30 (V72-era · `/workbench/v3` geometry+mesh modes) were time-bombed by V76's MainCanvasV3 swap from placeholders to VtkCanvasV3. All 3 patched with `vtk-canvas-mounted-OR-vtk-webgl-fallback` waitForFunction. Without that wait, the screenshot tool would race the vtk init.
- The vtk.js kernel infrastructure existed since M-VIZ (V61 era) but had never been wired into the v3 surface. **6 arcs of "vtk.js carry" was a wiring debt, not an implementation debt.** V76 retro discusses this lesson.

### What V76 measured for the first time
- Pillar 15's existence forces real WebGL 3D viz as a first-class score axis. V75 had placeholders; V76 has a mounted vtk canvas with full HUD overlays.

### What V76 fixed for all future arcs
- **Literal-testid scorer trap** (carry from V73.4 / V74.3 / V74.5 / V75.1): scorer regexes for `data-testid` now accept literal AND template-expression forms via `data-testid=[\"\`{][^\"\`}]*<suffix>`. Future arcs no longer need 4-subclass workarounds to score correctly.
