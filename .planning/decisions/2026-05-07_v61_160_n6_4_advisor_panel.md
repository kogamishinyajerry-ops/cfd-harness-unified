# DEC-V61-160 · N6.4 · AI Advisor Panel (Frontend)

## Scope

Add the frontend surface for the V130 advisory entry points
(AI 审查 / AI 诊断). Renders inside the right-rail Body region in
`TaskPanel`, after `CompletenessCard` and before the step-specific
Body. Two buttons trigger `GET /api/cases/{id}/ai-review` and
`GET /api/cases/{id}/ai-diagnose`; results render as findings/
hypotheses with citation chips + copy buttons; **no apply controls
anywhere in the rendered tree**.

## Surface delivered

- `ui/frontend/src/types/ai_advisor.ts` — wire types mirroring
  backend `schemas/ai_advisor.py` (CitedChunk, ReviewFinding,
  ReviewResponse, DiagnosisHypothesis, DiagnoseResponse, FailureMode,
  FindingArea, FindingSeverity, FindingSource, HypothesisLikelihood)
- `ui/frontend/src/api/client.ts` — `api.getAIReview(caseId)` +
  `api.getAIDiagnose(caseId, problemHint?)`
- `ui/frontend/src/pages/workbench/step_panel_shell/AIAdvisorPanel.tsx`
  — main panel component (review/diagnose tabs, advisory-only
  badge, citation chip with click-to-expand, copy-only buttons,
  degradation banner, error banner)
- `ui/frontend/src/pages/workbench/step_panel_shell/TaskPanel.tsx`
  — wired into right rail after CompletenessCard
- `ui/frontend/src/pages/workbench/step_panel_shell/__tests__/AIAdvisorPanel.test.tsx`
  — 12 tests

## Notes

- Layout decision: AIAdvisorPanel sits **inside the scrollable
  Body** (alongside CompletenessCard) rather than pinned-bottom.
  Keeps the existing AICoachPanel chat surface (DEC-V61-120)
  untouched; the two AI entry points are visually distinct
  (advisory cards vs. chat box).
- Citation chip is intentionally subtle — small underlined font.
  Engineer can drill in but it doesn't dominate the visual.
- Copy buttons use `navigator.clipboard.writeText()` with a
  best-effort try/catch (clipboard API may be unavailable in some
  embed contexts; failure is silent so the engineer can fall back
  to manual select-copy).
- N6.5 will broaden the rule-based fallback emitter set on the
  backend; UI shape remains stable (same ReviewFinding /
  DiagnosisHypothesis schema with `source: "rule_based"`).
