# DEC-V61-155 · N5.4 Export Formats

## Status

**Accepted 2026-05-07** — V133 sub-DEC slim 6-field. Low-risk per N5
charter "low | no [Pre-merge Codex]". Pure read-only string/byte
producers; no V132 mutator. Closes the N5 phase: charter (N5.0) +
4 sub-DECs (N5.1-N5.4) all Accepted.

## Decision

Land two pure export utilities:

- `centerline_csv(samples)` — RFC-4180 CSV from a list of
  `CenterlineSample(position, fields)` records
- `grid_svg(panels, *, width, height)` — minimal 2×2 grid SVG with
  embedded PNG bytes via `data:image/png;base64,...` URLs

Both are byte-reproducible: same input → identical bytes.

## Wire shapes

```python
@dataclass(frozen=True)
class CenterlineSample:
    position: float
    fields: dict[str, float]

@dataclass(frozen=True)
class GridPanel:
    title: str
    png_bytes: bytes | None
    alt_text: str = ""

def centerline_csv(samples: list[CenterlineSample]) -> str: ...
def grid_svg(panels: list[GridPanel], *, width=1200, height=900) -> str: ...
```

## CSV behavior

- Empty input → `"position\n"` (header only)
- Header is `position,<sorted-union-of-field-keys>`
- Missing field for a sample → empty cell
- Number formatting: `0.0 → "0"`, `[1e-4, 1e6) → fixed-point` with
  trailing zeros stripped, otherwise `<value>.6e`
- RFC 4180 quoting on values containing comma / quote / newline
  (defensive — number formatting won't produce these, but the
  escape helper is correct if a future caller passes string fields)
- Unix line endings (`\n`)

## SVG behavior

- 2×2 layout at 1200×900 default size; cells are
  `(w/2) × (h/2)` with 30 px title band
- Up to 4 panels rendered in row-major order; extras truncated;
  fewer panels leave missing cells empty with `(no figure)` placeholder
- PNG bytes embedded via base64 `data:image/png;base64,...` URL
- XML escaping on title / alt_text content
- Raises `ValueError` on non-positive width/height
- Byte-reproducible (no wall-clock; deterministic base64; sorted
  panel order)

## Out of scope (charter §"Out of scope" + N5-extend)

- True vector field plots (matplotlib SVG backend integration) —
  defer to N5-extend
- Custom panel arrangements beyond 2×2 — defer
- Theme / styling beyond default sans-serif — defer
- Per-figure PDF export — engineer can use external tool on
  the SVG output
