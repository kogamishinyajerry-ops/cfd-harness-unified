### Substrate fragility uncovered

- **DemoBannerV4 hook-order bug on first cinematic-mode test attempt**: I initially placed `useRef` + `useEffect` AFTER the early-return for cold state, which violates React's hooks-must-be-in-same-order rule. Caught by the test (rendered the active-demo branch, hooks count changed). Fix was 30 LOC: move `useRef` and `useEffect` to the top of the component, before any conditional returns; the effect body guards on `cinemaActive` so it's safe to always-register. **Lesson**: when adding state to a component with conditional early-returns, all `useState`/`useRef`/`useEffect` MUST live above the first return statement. Pattern worth grepping for across the codebase (V84 candidate).
- **AdvisorContent useSearchParams broke router-less tests**: I added `useSearchParams` directly inside AdvisorContent to detect `?failmode=1` — this broke 7 of the existing router-less contract tests. Fix: lifted `failmodeActive` to a prop passed from WorkbenchShellV3 (which is already inside a Router). **Lesson**: shared components should NOT take direct Router dependencies; receive Router-derived state as props. This keeps unit tests cheap (no Router wrapping needed).
- **Hot-rerun discipline kept the close gate clean**: instead of running the V78 fleet after every sub-DEC, I batched all of V83.1-V83.5 first and ran scorers at the end. iter-0 came back 100/100 immediately. This matches the V82 close pattern — substrate orthogonality + late scoring is cheaper than per-sub-DEC scoring.
