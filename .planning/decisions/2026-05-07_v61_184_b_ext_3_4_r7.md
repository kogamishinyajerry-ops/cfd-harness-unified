## New findings (B-ext-4 candidates)

### F11 — /run-history empty after successful /solve

```bash
GET /api/cases/<case_id>/run-history → 200 {"runs": []}
```

Run registry not populated by /solve. Step 6 prompts route persona
through /run-history to discover run_id for /results/{run_id}/
field/{name}; without populated runs, that fetch path is broken.

### F12 — LDC defaults on non-cube geometry produce NaN field

```bash
GET /api/cases/<case_id>/results-summary
  → 422 results_malformed: U field contains 1584 NaN/Inf entries
```

icoFoam "converges" residuals but produces NaN U field on NACA0012
when persona uses LDC defaults (`from_stl_patches=0`). Root cause:
LDC-default lid_velocity=(1,0,0), nu=1e-3, Re=100 with bbox-derived
"lid"+"fixedWalls" patches doesn't correspond to airfoil physics.
Verdict-eligible state requires `from_stl_patches=1` with
case-physics bc_contract (Re~1e6 for external aero, ν=1.45e-5 m²/s,
proper inlet/wall classification).
