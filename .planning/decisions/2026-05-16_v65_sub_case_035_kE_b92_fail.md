# DEC-V65-A-sub-M-V65A-B92-KE-WALLFN-MISMATCH · kEpsilon y+~1 anti-pattern documented

## 1 · Decision

Cloned B91 case_035 substrate, switched turbulence model from kOmegaSST → kEpsilon (tutorial setup), kept same NASA TMR canonical y+=1 mesh (305k cells). simpleFoam ran 5000 iter to strict-FULL residuals (Ux ~6e-7, epsilon 1.3e-9, k 3.7e-9). **Cf vs Wieghardt experimental Δ% = {+66.88, +66.47, +66.21, +66.04, +65.94} — uniform +60-67% over-prediction at all 5 stations.** FULL attempt FAILED. **Root cause**: kEpsilon standard wall function assumes log-law region (y+ > 30), but mesh y+~1 (avg 1.21) falls in viscous sublayer. Wall function mis-applies in low-Re region → massive τ_w over-prediction.

## 2 · F-NEW-kEpsilon-wallfn-mismatch candidate captured

**Signature** (1st observation):
> "Standard kEpsilon RAS turbulence model + y+~1 mesh (designed for low-Re-class models like kOmegaSST or Spalart-Allmaras) causes ~60% Cf over-prediction on flat plate. Root cause: kEpsilon wall function (epsilonWallFunction + kqRWallFunction + nutkWallFunction) assumes log-law region applicability (y+ > 30), but at y+~1 the wall function asserts log-law equations in viscous sublayer where they don't hold. Workaround paths: (a) switch to kOmegaSST/SA for y+~1 meshes, OR (b) use kEpsilonLowReWallFunction variants, OR (c) coarsen mesh to y+ > 30."

This is a methodology-class F-NEW. To LAND as V-row needs 2nd witness (e.g., kEpsilon on bump2D y+~1 mesh confirming same pattern).
