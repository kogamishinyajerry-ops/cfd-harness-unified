# DEC-V61-157 · N6.1 · RAG Corpus Loader

## Scope

Build the read-only corpus loader that powers N6.2 (AI 审查) and
N6.3 (AI 诊断). Allowlisted roots: `docs/openfoam_corpus/` +
`.planning/decisions/`. Markdown-only ingestion; sections split on
`##`-or-deeper headers; SHA-256 per chunk; stable `chunk_id`.

## Surface delivered

- `ui/backend/schemas/ai_advisor.py` — `CitedChunk`, `CorpusStats`
  wire schemas (`extra=forbid`, 64-hex SHA bound, 4096-char text cap)
- `ui/backend/services/ai_advisor/__init__.py` — package public surface
- `ui/backend/services/ai_advisor/corpus_loader.py` — `load_corpus`,
  `get_default_corpus`, `reset_default_corpus`, `Corpus.find_relevant`,
  `Corpus.get_chunk`
- `docs/openfoam_corpus/` — seed corpus (5 hand-curated topic docs +
  README): mesh quality / solver selection / BC basics / URFs /
  residual diagnostics
- `ui/backend/tests/test_n6_1_corpus_loader.py` — 25 tests covering
  schema + loader + lookup + V130 advisory-only contract

## Four-question gate

| # | Question | Answer |
|---|---|---|
| Q1 | LLM offline → engineer can complete? | ✅ Loader has zero LLM/network deps; runs purely on local files |
| Q2 | Artifacts output? | ✅ `Corpus.stats.corpus_sha` is the load-time fingerprint; per-chunk SHA on every `CitedChunk` |
| Q3 | TrustGate / completeness / audit explainable? | ✅ Each chunk carries path + byte_offset + sha; engineer can `shasum` the chunk text on disk to verify |
| Q4 | AI advisory only (no mutating call)? | ✅ Module structurally not in `KNOWN_MUTATION_FUNCTIONS`; static AST test asserts no import of any mutation symbol; case-directory paths excluded from allowlist |

## Confidence

`high` — pure read-only data structure, no I/O risks beyond filesystem

charter ("per Opus confidence" for N6.1).

## Notes

- Lookup: keyword token-overlap, anchor weighted 2x; ties broken by
  `chunk_id` ascending for determinism
- `chunk_id` shape: `<repo-relative-path>:<byte_offset>:<sha[:16]>` —
  stable across runs as long as content unchanged
- `corpus_sha` is sha256 of sorted `chunk_id:sha` pairs; suitable for
  audit manifest inclusion
- V1 ingests markdown only; `.txt`/`.yaml` skipped silently
- Embedding-based retrieval deferred to N6-extend if recall regresses
