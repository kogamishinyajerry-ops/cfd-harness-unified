regenerating polyMesh back to single-`patch0` state and leaving

(`Cannot find patchField entry for patch0`).

clear `mesh_bc_mismatch` error when 0/<field>/boundaryField keys
reference patches not in polyMesh/boundary. Route maps to HTTP 409
with explicit remediation hint. Replaces the cryptic 502 +
OpenFOAM IO error path.

**Fix 2** (`mesh_imported_case` eager invalidation): after a
successful gmshToFoam, removes 0/, 0.orig/, and clears 0/* manifest
user-overrides. Next /setup-bc authors fresh BC files matching the
new mesh.
