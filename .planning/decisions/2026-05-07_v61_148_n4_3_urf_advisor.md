# DEC-V61-148 · N4.3 URF Advisor

## Status

**Accepted 2026-05-07** — V133 sub-DEC slim 6-field. Medium-risk per
N4 charter; Opus confidence high — pure schema + rule-based advisor,
no mutation surface, no V132 entry. No Codex pre-merge mandate.

## Decision

Land per-equation URF override schema + a stability advisor that
emits informational hints when factors look too aggressive for the
declared regime. Charter §threat-model row 4: "URF advisor must NOT
be an AI mutator — pure rule-based read-only suggestion" — enforced
by structure (advisor is a pure function returning dataclasses).

## Wire shape

```python
class URFOverride(BaseModel):  # extra=forbid
    fields: dict[str, float]      # field_name → factor in (0, 1]
    equations: dict[str, float]   # eq_name → factor in (0, 1]
    authored_at: str
```

Field/equation name charset: alnum (matches OpenFOAM convention `U`,
`p`, `pFinal`, `k`, `omega`, `epsilon`).

Range: factor MUST be in (0, 1]. Zero stalls the solver; > 1 is
unstable.

## Stability advisor thresholds

| target | safe ≤ | warning band | critical > |
|---|---|---|---|
| equations.U (RANS) | 0.7 | 0.7-0.85 | 0.85 |
| equations.U (laminar) | 0.7 | 0.7-0.9 | 0.9 |
| equations.{k,omega,epsilon} | 0.7 | 0.7-0.85 | 0.85 |
| fields.p | 0.3 | 0.3-0.5 | 0.5 |

LES-stub regime: when ANY URF is set, emit an info hint that LES
typically doesn't use SIMPLE/PIMPLE relaxation in the same way.
LES + empty override → no hint.

## V130 / V132 enforcement

- Schema accepts engineer input only — no AI auto-fill path
- Advisor returns `list[StabilityHint]` dataclasses; **no disk
  write, no API mutation, no auto-tune**
- Advisor module is NOT in `KNOWN_MUTATION_FUNCTIONS` (test asserts
  this — V130 contract)
- The hints are rendered as colored badges in the URF panel; engineer
  reads + decides

## Hint sort order

Critical first, then warning, then info; alphabetic by `target`
within each severity bucket. Tests pin both invariants.

## V132 contract

This sub-DEC adds NO mutation route. The actual writer that
translates URFOverride → fvSolution `relaxationFactors` block is
deferred to N4.5 / N4-extend (which lands the unified solver-config
commit route consuming URFOverride + SolverDictsOverride from N4.2 +
ControlDictTiming from N4.5).
