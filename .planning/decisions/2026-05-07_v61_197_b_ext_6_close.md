## What B-ext-6 did NOT deliver

- **Real-physics verdict pass on backward_step** (observed L/h ≈ 6.0).
  Two structural blockers:
  1. **Cell-center exposure** — `simpleFoam` and `icoFoam` don't
     write Cx/Cy/Cz by default. Without spatial info, persona can't
     locate where u_x changes sign on the lower wall (the L/h
     metric definition).
  2. **LDC defaults wrong physics** — current prestage path uses
     `from_stl_patches=0` (LDC defaults) on backward_step STL because
     the STL is single-shell with no named solids. Real physics needs
     either named-solid STL fixtures or workbench-side patch-split
     scaffolding before from_stl_patches=1.
- **B-ext-6.2 cell-center exposure sub-DEC** — not opened. Would
  need either:
  - Server-side: invoke `postProcess -func writeCellCentres -time
    <final>` in the OpenFOAM container post-solve, then expose
    /field/Cx, /field/Cy, /field/Cz via the (now-vector-aware)
    field route.
  - Or extension to /results-summary that includes case-class-specific
    computed metrics (e.g., `reattachment_length_over_h` for
    backward_step) computed server-side from polyMesh + U.

These are escalated to **B-ext-7** as a single charter focused on
real-physics verdict pass.

## Recommendation for B-ext-7

**Single tightly-scoped charter:** real-physics verdict pass on
backward_step / novice with observed L/h close to Kim 1980's 6.0.

Sub-DECs:

1. **B-ext-7.1 Cell-center exposure** — post-solve `writeCellCentres`
   hook in solver_runner; add Cx/Cy/Cz to scalar field path so
   /field/Cx works. Small (~50 LOC + tests).
2. **B-ext-7.2 Reattachment computation** — choose either:
   - **Option A**: extend /results-summary with optional
     `reattachment_length_over_h: float | None` populated when geometry
     hint indicates backward-step (server-side numpy scan along lower
     wall using U + Cx/Cy). Cleaner schema; case-class detection needed.
   - **Option B**: persona-side scan (rehearsal driver pulls /field/U
     + /field/Cx + /field/Cy and computes locally). More flexible; no
     schema change but more LLM tokens.
3. **B-ext-7.3 Real-physics path** — get backward_step running with
   actual incompressible RANS (simpleFoam + kOmegaSST) instead of LDC
   defaults. Requires either named-solid STL fixtures or workbench-side
   patch-split helper for single-shell STL geometries. **This is the
   hardest sub-DEC** and the actual remaining bottleneck.
4. **B-ext-7.4 Final rehearsal + close** — Variant A v3 with real
   physics + cell centers; aim for observed L/h within Kim 1980's
   ±10%. If not, close B-ext-7 with finding documenting which layer
   is still missing.

If B-ext-7.3 (real physics path) turns out to be its own multi-DEC
arc, split it into B-ext-7 (cell centers + reattachment scan with LDC
defaults producing physically-wrong-but-well-defined L/h) and
B-ext-8 (real-physics path).
