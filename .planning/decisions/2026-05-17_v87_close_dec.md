### Substrate fragility uncovered

- **V87.2 baseline 84/85 initially failed because BottomPanel auto-expands at Step ≥4.** First snap attempt: button not visible because the collapsed bar where it lives wasn't rendered. Fix: add `?btab=closed` to baseline URLs (`urlBtab === "closed"` forces bottomCollapsed=true · overrides Step-4-auto-expand default). 2 baseline retries · iter-0 still clean because failures surfaced BEFORE the scorer ran. **Lesson**: when adding visual baselines for components mounted inside collapsible containers, explicitly force the collapse state via URL query rather than relying on default. Default auto-behavior is implicit state that drifts as substrate evolves.
- **V87.2 LIVE pill baseline is the absence-of-pill at idle (test 86).** The pill renders only during `starting` / `running` · I can't drive a real solver run inside a visual baseline. So test 86 captures the EMPTY TopBar — proving the pill doesn't leak into idle. A future V88+ extension could add a `?force_solver_state=running` URL flag (test-only · gated by `import.meta.env.DEV`) for driving the running-state baseline. **Lesson**: not all visual surfaces are baseline-able directly · sometimes the "absence" baseline is the right surface and a state-injection harness is V8+ scope.
- **Charter §3 "Zod guard" wording was aspirational.** Surface-scan-style discipline applied at sub-DEC implementation: discovered Zod not installed, evaluated cost-vs-benefit (new dep · 50KB runtime overhead vs ≤80 LOC of plain TS guards), chose plain TS. Decision documented in `sseSchemaGuardV7.ts` header. **Lesson**: charter-level technology naming is non-binding when sub-DEC surface scan reveals a simpler equivalent. Update retro language; don't pretend you used Zod.
- **bridge artifact handoff structurally types RunDetail as BridgeArtifact.** V87.1 uses `runDetailQuery.data as unknown as BridgeArtifact` — relies on TypeScript structural typing. This works because RunDetail is a superset of BridgeArtifact's required fields. V87.4 schema guard provides additional runtime safety (residual events from REAL SSE), but the RunDetail→BridgeArtifact cast is unchecked at runtime. **Lesson**: structural typing across module boundaries is fine for shipped substrate but should be flagged in retro as a potential V88+ Zod-or-equivalent guard target if schemas drift.
