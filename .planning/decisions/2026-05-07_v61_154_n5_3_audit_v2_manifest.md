# DEC-V61-154 · N5.3 Audit V2 Manifest

## Status

**Accepted 2026-05-07** — V133 sub-DEC slim 6-field. Medium-risk per

## Decision

Land the V2 provenance manifest schema + builder + byte-reproducible
canonical-bytes serializer. Reuses existing HMAC infrastructure
(`src/audit_package/sign.py` from DEC-V61-014) — does NOT introduce
a new secret per charter §threat-model row 3.

## Wire shape

```python
class ProvenanceManifest(BaseModel):  # extra=forbid
    schema_version: Literal["v2"] = "v2"

    case_state_sha: str           # SHA-256 hex (64 chars)
```

## case_state_sha computation

Stable byte stream over a fixed file order:

| Order | Path | Source |
|---|---|---|
| 1 | `constant/polyMesh/points` | mesh |
| 2 | `constant/polyMesh/owner` | mesh |
| 3 | `constant/polyMesh/neighbour` | mesh |
| 4 | `constant/polyMesh/boundary` | mesh |
| 5 | `constant/polyMesh/faces` | mesh |
| 6 | `constant/physicalProperties` | N3.3 physics |
| 7 | `constant/momentumTransport` | N3.3 physics |
| 8 | `0.orig/U` | N4.1 BC |
| 9 | `0.orig/p` | N4.1 BC |
| 10 | `system/controlDict` | solver |
| 11 | `system/fvSchemes` | solver |
| 12 | `system/fvSolution` | solver |

Per-file record format:
```
<rel_path>:<size>:<bytes>\n   # when file present
<rel_path>:MISSING\n          # when absent
```

Missing files contribute the literal "MISSING" sentinel so adding a
previously-absent file changes the SHA. Engineer can detect "engineer
just added 0.orig/U" by SHA delta.

## Byte-reproducibility (charter §verification final bullet)

`canonical_manifest_bytes(manifest)` uses
`json.dumps(payload, sort_keys=True, separators=(",", ":"))` and
**excludes the `authored_at` field**. Two manifests with the same
case state but different wall-clock authored_at produce identical
canonical bytes → identical SHA when fed to the existing HMAC
signer (`src/audit_package/sign.py:sign(manifest_bytes, zip_bytes,
key)`).

Test `test_canonical_bytes_excludes_authored_at` pins this invariant.
