## Treatment policy

Each row above must be visible somewhere in the system:

- a schema constraint that enforces it, OR
- a test that fails when it is violated, OR
- a Red Team checklist item that catches it.

Risks that exist only in this document, without one of those three hooks,
are notional and do not count as managed.
