# `_w71a_wedge_probe_SYNTHETIC` — SYNTHETIC offline fixture (NOT a solver run)

> **READ THIS FIRST.** This directory is **NOT** the output of an OpenFOAM /
> rhoCentralFoam solve. There is no mesh, no solver, no convergence here. It is a
> hand-constructed `postProcessing/` tree generated by
> [`_build_synthetic_fixture.py`](_build_synthetic_fixture.py), and exists ONLY so
> the P4 wedge-oblique-shock **gate's parsing + fail-closed logic** can be exercised
> in CI without a live solver.

## Why synthetic (and why that is honest)

`rhoCentralFoam` (the density-based shock-capturing solver this benchmark anchors)
**cannot run on the local image**: the OpenFOAM **OF11 Foundation** image present on
disk has no `rhoCentralFoam`, and the adapter's OF10/ESI image is absent — the fork
wall recorded in **DEC-V61-224** (*"P4 (rhoCentralFoam) will re-hit the same wall"*).
Per **DEC-V61-232** the sponsor chose **scaffolding-first**: author the honesty-
critical V&V logic now (offline), and defer the ESI-image provision + live run to a
separate gated slice.

The split of duties keeps this honest:

| Concern | Locked by | Uses this fixture? |
|---|---|---|
| The physics **reference** (β, M2, p/ρ/T ratios) cannot drift / be fabricated | `tests/p4/test_wedge_oblique_shock_gold.py` (re-derives θ-β-M from inputs) | **No** — pure math |
| The **gate code** parses solver artifacts + fails-closed on doctored input | `tests/p4/test_wedge_oblique_shock_gate.py` | **Yes** — exercises parsing/anti-cheat |
| The harness can **actually run** rhoCentralFoam + match the gold (coverage 2→3) | a **LIVE** frozen probe (deferred slice) | replaces this fixture |

This fixture validates **code**, not physics. It does **NOT** flip runnable-coverage
2→3; the gold's `contract_status` stays `ANALYTICAL_REFERENCE_AUTHORED · LIVE_RUN_PENDING`.

## What it contains

`postProcessing/` with 8 single-field `surfaceFieldValue` area-averages
(`freestream_{p,rho,T,Ma}`, `postShock_{p,rho,T,Ma}`) and one `shockLine/…/line_rho.xy`
density sample crossing the shock. Values correspond to an analytical M₁=2.0, θ=15°
oblique shock, with the post-shock state made ideal-gas consistent (p₂=ρ₂RT₂) and
β (45.0°) / M₂ (1.44) deliberately a hair off the exact gold references
(45.34° / 1.4457) — so the gate tests can prove it **measures** rather than echoes.

## Reproduce

```bash
python3 reports/showcase_aero/_w71a_wedge_probe_SYNTHETIC/_build_synthetic_fixture.py
pytest -q tests/p4/
```

When the live slice lands, a **real** converged-tail `rhoCentralFoam` probe replaces
this directory and the gate test's `_PROBE` points at it.
